# Git Calculator

A simple command-line calculator written in Python.

## About This Repository

This repository was originally created as a practical Git and GitHub training project for teaching university classmates the basic concepts of collaborative software development.

The main goal of the project is not to build a complex calculator. Instead, it provides a small and simple project where students can practice a real Git workflow, including:

* Cloning a repository
* Creating and using branches
* Making commits
* Pushing changes to GitHub
* Creating pull requests
* Reviewing changes
* Merging branches into `main`

## Features

The calculator provides basic mathematical operations, including:

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Remainder

## How It Works

The project is designed as a collaborative exercise.

Each team member works on a separate feature branch and implements a specific part of the calculator. After completing the assigned task, the student commits the changes, pushes the branch to GitHub, and creates a Pull Request to merge the changes into `main`.

All team members work on the same `calculator.py` file. This makes the project useful for practicing branch management, pull requests, code review, and merge conflicts.

## Educational Purpose

This repository was created specifically as a hands-on exercise for university classmates who were learning Git and GitHub.

The project demonstrates how a small software project can be developed collaboratively using a version control system.
