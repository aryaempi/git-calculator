# Contributing

This repository is a Git and GitHub training project.

The project is designed to help university classmates practice collaborative development using Git and GitHub.

## Workflow

Contributors should follow this workflow:

1. Clone the repository.
2. Create a new feature branch.
3. Work only on the assigned part of the project.
4. Commit the changes with a clear commit message.
5. Push the branch to GitHub.
6. Open a Pull Request to `main`.
7. Wait for the changes to be reviewed.
8. Merge the Pull Request after approval.

## Important Rules

* Do not work directly on the `main` branch.
* Keep changes related to the assigned task.
* Use clear and meaningful commit messages.
* Do not modify another contributor's assigned section unless necessary.
* Test the program before creating a Pull Request.
